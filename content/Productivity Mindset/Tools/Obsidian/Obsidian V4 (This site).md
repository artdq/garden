# About
This is the first version I've actually made public. For the purposes of PPD, I've only included notes relevant to the project, but ultimately, I'll migrate all publicly-oriented notes to this vault.

Obsidian has a paid service where you can publish a vault, however with a bit more setup, you can self-host at no cost. There are several pieces of software for this purpose. I used one of the most popular, Quartz. There are many free plug-ins and other support for Obsidian because it is open source.

About Quartz: https://quartz.jzhao.xyz/ 

I followed the developer guide on setting up Quartz, hosting it via a github account.
