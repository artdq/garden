# About
In this version, I used Obsidian as a project management tool. For my final project, I organized my research, assignment information, and notes in these documents. I also intended to log general notes and resources from the curriculum into a digital garden here, even setting up file folders, but never followed through. 
# Reflection
At its most successful, it helped me keep certain information at my fingertips, like assignment criteria, research summaries and my source list. However, the default user interface doesn't work well for task management -- since it's all text-based, I realized I was missing features like the built-in deadline calendar, color coding, or subtask checklists that I appreciate in project management software like Asana. With the main selection interface being the file folder structure, it also became clear that trying to use a single vault for everything quickly created a long overwhelming list of items, regardless of folder structure.
