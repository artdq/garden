# About
During the winter holiday, I ended up down a rabbit hole on personal knowledge development systems like Zettelkasten, second brains, and digital gardening. People use them for all-purpose organization across all areas of life with information like personal to-do lists, research projects, and ideas they don't want to forget.

My first note was about setting up the system, screenshot below:
![[Screenshot 2026-09-26 102713.png]]
Obsidian organizes your entries as notes as markdown documents within a file folder structure.  Each note can hold properties, essentially metadata, to organize them further. Properties like tags and the date created/modified are built-in, but there's endless customization. As a well-supported open source software, there is a host of community plugins to support advanced features. It also supports workflow automation. Collections of notes are siloed in their own vaults, which can be customized separately.

# Reflection
This version did not catch on for me starting semester 2; I completely failed to build a habit. Since the main project was collaborative, it's not a natural workflow to organize project information or tasks privately on top of the groups shared systems. For rolling out an all-purpose organization, my projects at the time were a poor match. In theory, this could be overcome with intentional effort, but my aim is to build an organization system that comes naturally to me.
