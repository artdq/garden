# About
I decided to try using Obsidian again for task management, this time using a plug-in designed for that purpose. (https://tasknotes.dev)

I chose this plugin because it has many features like Asana, which I've used successfully in the past. I wanted to organize tasks via drag-and-drop, set subtasks and projects, and view tasks on a calendar of deadlines. 
# Reflection
I'm very pleased by the Kanban and calendar interfaces for viewing notes -- it makes it a million times more usable.

I realized I've also underexplored the Canvas interface, which is a Google Jamboard-style field where you can link elements across your vault. The more visual, drag-and-drop interface clicks with me.

I still need more visual cues on the interfaces to make it more skimmable. I'd like to see how I can customize some color coding in my Obsidian vaults generally.
